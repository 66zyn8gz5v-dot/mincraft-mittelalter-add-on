# ⚔ Mittelalter-Kampf – Minecraft Bedrock Add-on

Öffentliche Auslieferung des Add-ons (12 mittelalterliche Waffen in 4 Stufen, neues 1v1-Kampfsystem).
Der Quellcode wird in einem privaten Repository entwickelt; hier liegen nur die fertigen Pakete.
Sie werden bei jeder Weiterentwicklung (auch nachts) automatisch aktualisiert.

## Download für den iPad-Kurzbefehl

|---|---|---|
| `paket_verhalten.zip` | `development_behavior_packs` | https://raw.githubusercontent.com/66zyn8gz5v-dot/mincraft-mittelalter-add-on/main/auslieferung/paket_verhalten.zip |
| `paket_bilder.zip` | `development_resource_packs` | https://raw.githubusercontent.com/66zyn8gz5v-dot/mincraft-mittelalter-add-on/main/auslieferung/paket_bilder.zip |
